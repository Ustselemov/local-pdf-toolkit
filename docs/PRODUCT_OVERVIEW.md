# Product Overview

This project was generated with the assistance of Codex AI and prompted by Ustselemov.

## Purpose

Local PDF Toolkit provides a private alternative to online PDF tools. The product focuses on page-level document operations that can run entirely in the browser without sending files to a server.

## Product Goals

- Keep user documents local to the machine
- Cover the most common PDF page operations
- Remain easy to run and inspect as a static project
- Be maintainable as a public repository

## Current Scope

- Import PDF, JPG, PNG
- Display page previews
- Reorder, rotate, delete, extract, split, and export pages
- Apply watermark and page number overlays on export
- Export as PDF or JPEG

## Non-Goals

- Full document text editing
- OCR
- Certificate-backed digital signatures
- Cloud synchronization
