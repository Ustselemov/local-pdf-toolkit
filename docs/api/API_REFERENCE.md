# API Reference

This project was generated with the assistance of Codex AI and prompted by Ustselemov.

This project does not expose a network API.

## Internal Browser Interfaces

The runtime is driven by DOM events in `app.js`, with helper modules in `src/` handling file detection, image loading, split parsing, overlay rendering, stamp editing, JPEG presets, and browser export helpers.

## External Surface

- Local file input
- Drag-and-drop import
- Export buttons for PDF and JPEG
- Overlay controls for watermark and page numbers
- Fullscreen image stamp editor for per-page stamp placement
