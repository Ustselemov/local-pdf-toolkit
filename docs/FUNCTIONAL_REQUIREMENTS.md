# Functional Requirements

This project was generated with the assistance of Codex AI and prompted by Ustselemov.

## FR-1 Import

- The system shall import local PDF files.
- The system shall import local JPG and PNG files.
- The system shall support click-to-select and drag-and-drop import.

## FR-2 Workspace

- The system shall display imported pages as visual previews.
- The system shall allow reordering pages.
- The system shall allow rotating pages.
- The system shall allow deleting pages.
- The system shall allow selecting multiple pages.

## FR-3 Export

- The system shall export the current workspace as a PDF.
- The system shall export pages as JPEG files.
- The system shall allow extracting selected pages.
- The system shall support split export by explicit page ranges.

## FR-4 Overlays

- The system shall allow entering watermark text.
- The system shall allow choosing a watermark position preset.
- The system shall allow enabling page numbers.
- The system shall allow choosing page number format and position preset.
