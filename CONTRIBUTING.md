# Contributing

This project was generated with the assistance of Codex AI and prompted by Ustselemov.

## Setup

1. Install Node.js 20+.
2. Run `npm install` in the repository root.
3. Open `index.html` directly in a current Chromium-based browser.
4. Run `npm.cmd test` before submitting changes.

## Contribution Rules

- Keep the project browser-only and offline-first.
- Do not add server dependencies for core document processing.
- Do not introduce secrets or private credentials into the repository.
- Update documentation when functionality or constraints change.
- Preserve local-first privacy guarantees.

## Pull Requests

- Keep changes scoped.
- Include a concise summary of the change.
- Document testing performed.
- Call out any browser-specific limitations.
