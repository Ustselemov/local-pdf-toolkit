Product Brief

Local PDF Toolkit

Локальный браузерный PDF toolkit без сервера, без Python, без Docker и без загрузки личных файлов на сторонние сайты.

Текущее состояние: это уже рабочее offline browser-приложение для page-level операций с PDF и изображениями. Ниже зафиксировано только фактическое состояние продукта: что уже есть, чего еще нет и что делать дальше.

Что это за продукт

Что уже подтверждено

  • Работает локально в браузере.
  • Не требует backend, Python, Docker или серверной обработки файлов.
  • Фокусируется на операциях со страницами и экспорте, а не на глубоком редактировании содержимого PDF.

Чего продукт сейчас не делает

  • Не редактирует текст внутри PDF как в Word.
  • Не делает OCR для сканов.
  • Не делает продвинутое сжатие уровня desktop PDF-редакторов.
  • Не поддерживает сертификатные цифровые подписи.

Что еще не реализовано

Функции, которых сейчас нет

  • Crop страниц.
  • Metadata editing.
  • Batch workflows.
  • Flatten/export presets beyond the current flow.
  • OCR.
  • Advanced compression.
  • Digital signing.
  • Редактирование текста внутри PDF.

Текущие ограничения

  • Множественные JPEG-загрузки зависят от browser download policy.
  • Browser smoke test уже есть, но это еще не полноценный UI regression suite.
  • Проект стал модульнее, но app.js все еще остается orchestration entrypoint.

Текущая архитектура

Application shell

  • index.html для структуры UI.
  • styles.css для presentation layer.
  • app.js как entrypoint и orchestration layer.

Browser modules

  • src/common-helpers.js
  • src/file-helpers.js
  • src/image-helpers.js
  • src/overlay-helpers.js
  • src/split-helpers.js
  • src/workspace-helpers.js
  • src/stamp-helpers.js
  • src/stamp-editor.js
  • src/jpeg-helpers.js
  • src/export-helpers.js
  • src/export-controller.js
  • src/test-hooks.js
  • src/pdf-ops.mjs

PDF stack

  • pdf.js для preview rendering.
  • pdf-lib для PDF composition и export overlays.
  • Никаких внешних API.

Delivery model

  • Статическая папка файлов.
  • Запуск прямым открытием index.html.
  • Работа через file://.

Итоговая формулировка продукта

Локальный браузерный инструмент для импорта PDF, JPG и PNG, просмотра страниц, перестановки, удаления, поворота, извлечения, разделения, объединения и экспорта в PDF или JPEG без загрузки файлов на сервер.

Этот документ отражает текущее фактическое состояние проекта. Он не разделен на старые MVP-этапы и обновлен под текущую реализацию.
