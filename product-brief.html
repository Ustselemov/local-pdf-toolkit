Product Brief

Private Offline PDF Toolkit

Локальный браузерный PDF toolkit без сервера, без Python, без Docker и без загрузки личных файлов на сторонние сайты.

Идея продукта: пользователь открывает локальный HTML-файл, добавляет PDF с компьютера и выполняет базовые page-level операции полностью на устройстве.

Продуктовое обещание

Что обещаем

  • Работа полностью локально в браузере.
  • Без аккаунта, без облака, без серверной обработки файлов.
  • Фокус на операциях со страницами PDF, а не на сложной редактуре содержимого.

Что не обещаем

  • Редактирование текста внутри PDF как в Word.
  • OCR для сканов.
  • Профессиональное сжатие уровня desktop-редакторов.
  • Сертификатные цифровые подписи.

Что именно значит MVP 2

Watermarks

В первой реалистичной версии watermark это текстовая надпись, которая автоматически рисуется поверх выбранных страниц при экспорте. Базовый и понятный вариант: одна крупная полупрозрачная надпись по центру страницы по диагонали, например DRAFT или CONFIDENTIAL.

На первом шаге watermark не нужно делать свободно перетаскиваемым. Реалистичнее дать готовые пресеты: center diagonal, top center, bottom center.

Page Numbers

Page numbers это не магическая встроенная функция PDF, которая сама появляется из стандарта. Для локального web app это обычный текстовый overlay, который мы сами дорисовываем на страницу при экспорте: например 1, 2 или Page 1 of 10.

Для первой версии это должно быть просто и предсказуемо: по умолчанию внизу справа, с несколькими пресетами вроде bottom right, bottom center, top right.

Image to PDF

Это уже идет в правильную сторону продукта: изображения JPG/PNG загружаются в то же окно, становятся страницами общего workspace и дальше двигаются, удаляются, поворачиваются и экспортируются вместе с PDF-страницами.

Image Stamps

Image stamp это уже не просто импорт картинки, а наложение изображения поверх страницы: подпись, печать, логотип, скан автографа. Если делать это хорошо, stamp действительно должен ставиться в нужное место страницы, а не абстрактно "куда-то сверху".

Поэтому свободное позиционирование image stamp логично относить не к первому срезу MVP 2, а к отдельному fullscreen page editor, где можно открыть одну страницу крупно и двигать stamp мышкой.

Первый срез MVP 2

Уже сделано в коде

  • Landing принимает PDF, JPG и PNG.
  • Watermark с пресетами позиции уже добавлен в рабочий UI.
  • Page numbers с форматом и пресетами позиции уже добавлены в рабочий UI.
  • Изображения попадают в тот же workspace, что и PDF.
  • При экспорте одной страницы можно выбрать PDF или JPEG.
  • При экспорте всего workspace тоже можно выбрать PDF или JPEG.

Что важно помнить

Экспорт нескольких страниц в JPEG в браузере означает выгрузку нескольких файлов, обычно по одному файлу на страницу. Это нормально для локального браузерного инструмента, но зависит от настроек браузера на множественные скачивания.

Техническая архитектура

Frontend shell

  • HTML для структуры.
  • CSS для минималистичного UI.
  • JavaScript для всего поведения.

PDF rendering

  • Локальный browser-side preview через PDF.js.
  • Никаких внешних API.

PDF manipulation

  • Локальная генерация и перестройка PDF через browser-side библиотеку.
  • Фокус на page-level операциях.

Delivery model

  • Статическая папка файлов.
  • Запуск прямым открытием index.html.
  • Без backend и без local server.

Нефункциональные требования

  • Приложение должно работать без интернета в обычном сценарии.
  • Приложение не должно отправлять PDF пользователя на сервер.
  • UI должен оставаться минималистичным и понятным.
  • Критичные действия должны быть доступны максимум за 1-2 клика после загрузки PDF.
  • Поведение должно быть совместимо с обычным открытием локального HTML-файла.

Итог

Самая сильная формулировка продукта для первой версии:

Локальный браузерный инструмент для просмотра, перестановки, удаления, поворота, извлечения, разделения и объединения PDF-страниц без загрузки файлов на сервер.

Этот документ создан отдельно от рабочего приложения. Основной runtime-файл приложения остается в index.html.
